# Ankara road fixture

Small development query to FOSSGIS Valhalla, 2026-11-11. Route and matching trace are actual responses, not measured driving telemetry. Metadata and hashes are in the ignored local probe artifacts.

Road data © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright). [Improve the map](https://www.openstreetmap.org/fixthemap).
Routing: [Valhalla](https://valhalla.github.io/valhalla/) through [FOSSGIS development service](https://routing.openstreetmap.de/about.html).
Returned elevation dataset has not been independently identified/verified; elevation is not a licensed standalone terrain product delivered by this repository.
